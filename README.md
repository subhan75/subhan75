**Orbit.ai** · [repo](https://github.com/subhan75/Orbit.ai)
Modular MCP-agnostic developer productivity agent with real-time workflow automation and natural-language voice command execution. Won 3 sponsor tracks at CalHacks 2025 — the world's largest collegiate hackathon.

**RepairMate** · [repo](https://github.com/subhan75/RepairMate)
Multi-modal, multi-agent fault diagnosis from user-submitted video. Autogen, OpenCV, Whisper, VLMs. Applied model quantization — 87% smaller model, 70% faster inference, 85% fault detection accuracy.

**Rolofy** · [live](https://rolofy.online)
Digital identity platform — one scannable QR code for all your social and professional profiles. Solo-built end to end. Next.js, FastAPI, Supabase, Vercel. 2k+ impressions, 40+ profiles.
